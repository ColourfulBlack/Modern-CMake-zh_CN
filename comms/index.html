与你的代码交互

配置文件（Configure File）¶

CMake 允许你在代码中使用 configure_file 来访问 CMake 变量。该命令将一个文件（传统上以 .in 结尾）从一个地方复制到另一个地方，并替换其中找到的所有 CMake 变量。如果你希望避免替换输入文件中已有的 ${} 语法，请使用 @ONLY 关键字。如果只是用它来替代 file(COPY，还可以使用 COPYONLY 关键字。

这个功能使用得相当频繁；例如对于下面的 Version.h.in：

Version.h.in¶

#pragma once

#define MY_VERSION_MAJOR @PROJECT_VERSION_MAJOR@
#define MY_VERSION_MINOR @PROJECT_VERSION_MINOR@
#define MY_VERSION_PATCH @PROJECT_VERSION_PATCH@
#define MY_VERSION_TWEAK @PROJECT_VERSION_TWEAK@
#define MY_VERSION "@PROJECT_VERSION@"

CMake lines:¶

configure_file (
    "${PROJECT_SOURCE_DIR}/include/My/Version.h.in"
    "${PROJECT_BINARY_DIR}/include/My/Version.h"
)

在构建项目时，你也应该将构建目录（binary directory）下的头文件目录包含进来。如果你想在头文件中放入任何真/假（true/false）类型的变量，CMake 提供了 C 语言专用的 #cmakedefine 和 #cmakedefine01 替换指令来生成相应的宏定义行。

你也可以使用（并且经常使用）它来生成 .cmake 文件，例如包配置文件（见 installing）。

读取文件¶

反方向的操作同样可行；你也可以从源文件中读取内容（例如版本号）。举例来说，如果你有一个仅包含头文件的库，并且希望它在有或没有 CMake 的情况下都能使用，那么这就是处理版本号的最佳方式。写法大致如下：

# 假设规范版本号写在单独一行中
# 如果分别从 MAJOR、MINOR 等宏中读取，则需要拆分为几个部分
set(VERSION_REGEX "#define MY_VERSION[ \t]+\"(.+)\"")

# 读入包含版本号的那一行
file(STRINGS "${CMAKE_CURRENT_SOURCE_DIR}/include/My/Version.hpp"
    VERSION_STRING REGEX ${VERSION_REGEX})

# 仅提取出版本号本身
string(REGEX REPLACE ${VERSION_REGEX} "\\1" VERSION_STRING "${VERSION_STRING}")

# 自动获取 PROJECT_VERSION_MAJOR、My_VERSION_MAJOR 等变量
project(My LANGUAGES CXX VERSION ${VERSION_STRING})

在上面的代码中，file(STRINGS file_name variable_name REGEX regex) 选取了与正则表达式相匹配的行；随后使用同一个正则表达式提取出圆括号捕获组中的版本号部分，并通过反向引用替换仅输出该捕获组的内容。
