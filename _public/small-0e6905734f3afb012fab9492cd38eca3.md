# 为 CMake 项目添加选项

CMake 中有许多关于编译器和链接器的设置。当你需要添加一些特殊配置时，应该首先检查 CMake 是否支持它；如果支持，你就不必将自己显式绑定到特定的编译器版本。更好的是，你可以在 `CMakeLists.txt` 中清晰地表明你的意图，而不是堆砌一连串标志（flag）。

其中最首要、也是最常见的特性是对 C++ 标准的支持，这部分已经单独设有一章进行讲解。

## 地址无关代码（Position independent code）

[这项特性](https://cmake.org/cmake/help/latest/variable/CMAKE_POSITION_INDEPENDENT_CODE.html)最为人熟知的形式就是 `-fPIC` 标志。大多数情况下，你不需要做任何额外操作，CMake 会在 `SHARED` 以及 `MODULE` 类型的库中自动包含此标志。如果你确实需要显式声明，可以这样写：

```cmake
set(CMAKE_POSITION_INDEPENDENT_CODE ON)
```

这会对全局的目标进行此设置；或者也可以这样写：

```cmake
set_target_properties(lib1 PROPERTIES POSITION_INDEPENDENT_CODE ON)
```

来针对某个目标显式地将其开启（`ON`）或关闭（`OFF`）。

## Little libraries

如果你需要链接到 `dl` 库（在 Linux 上即 `-ldl` 标志），只需在 `target_link_libraries` 命令中使用内置的 CMake 变量 [`${CMAKE_DL_LIBS}`](https://cmake.org/cmake/help/latest/variable/CMAKE_DL_LIBS.html) 即可，不需要模块或使用 `find_package` 来寻找它。（这会添加使用 `dlopen` 与 `dlclose` 所需的一切依赖。）

遗憾的是，数学库就没有这么简单了。如果你需要显式地链接它，固然可以直接使用 `target_link_libraries(MyTarget PUBLIC m)`，但使用 CMake 通用的 [`find_library`](https://cmake.org/cmake/help/latest/command/find_library.html) 可能会更好：

```cmake
find_library(MATH_LIBRARY m)
if(MATH_LIBRARY)
    target_link_libraries(MyTarget PUBLIC ${MATH_LIBRARY})
endif()
```

通过快速搜索，你可以很容易地找到它以及其他所需库的 `Find*.cmake` 文件；大多数主流软件包都配有 CMake 模块的辅助库。更多信息请参见**包含现有软件包**章节。

## 过程间优化（Interprocedural optimization）

[`INTERPROCEDURAL_OPTIMIZATION`](https://cmake.org/cmake/help/latest/prop_tgt/INTERPROCEDURAL_OPTIMIZATION.html)，即大家熟知的 *链接时优化* 以及 `-flto` 标志，在 CMake 中得到了良好的支持。你可以通过变量 [`CMAKE_INTERPROCEDURAL_OPTIMIZATION`](https://cmake.org/cmake/help/latest/variable/CMAKE_INTERPROCEDURAL_OPTIMIZATION.html) 全局开启它，或者为单个目标指定 [`INTERPROCEDURAL_OPTIMIZATION`](https://cmake.org/cmake/help/latest/prop_tgt/INTERPROCEDURAL_OPTIMIZATION.html) 属性。如果编译器不支持该优化，在目标上将其设置为 `ON` 会产生报错（参见 [CMP0069](https://cmake.org/cmake/help/latest/policy/CMP0069.html)）。你可以使用内置模块 [CheckIPOSupported](https://cmake.org/cmake/help/latest/module/CheckIPOSupported.html) 中的 `check_ipo_supported()` 来提前检查编译器是否支持 IPO：

```cmake
include(CheckIPOSupported)
check_ipo_supported(RESULT result)
if(result)
  set_target_properties(foo PROPERTIES INTERPROCEDURAL_OPTIMIZATION TRUE)
endif()
```
