# OpenMP

使用现代（TM）CMake 将 [OpenMP] 添加到目标的方法如下：

```cmake
find_package(OpenMP)
if(OpenMP_CXX_FOUND)
    target_link_libraries(MyTarget PUBLIC OpenMP::OpenMP_CXX)
endif()
```

这不仅比传统的基于编译标志的方法更简洁，而且在需要时还能将库链接选项与编译选项分别正确设置。它同样支持 macOS 系统上的 OpenMP（前提是库文件可用，例如通过 `brew install libomp` 安装）。

[openmp]: https://cmake.org/cmake/help/latest/module/FindOpenMP.html
