Minuit2

Minuit2 支持独立模式（standalone mode），适用于 ROOT 不可用或未启用 Minuit2 构建的场景。本节将介绍推荐的用法，并探讨其集成设计方面的一些细节。

用法¶

无论是使用 ROOT 源码，还是使用单独发行的源码包，Minuit2 都可以通过标准的 CMake 方式使用：

# 如果需要，也可以先检查 ROOT 中是否包含 Minuit2，
# 然后改为链接到 ROOT::Minuit2

add_subdirectory(minuit2) # 或 root/math/minuit2
# 或者
find_package(Minuit2 CONFIG) # 构建目录或安装目录皆可

target_link_libraries(MyProgram PRIVATE Minuit2::Minuit2)

开发¶

对于如何将现代 CMake（CMake 3.1+）构建集成到现有框架中这一问题，Minuit2 提供了一个很好的解决范例。

为了兼容两套不同的 CMake 系统，主 CMakeLists.txt 会定义公共选项，并在不作为 ROOT 一部分进行构建时调用 Standalone.cmake 文件。

ROOT 场景中最棘手的部分在于，Minuit2 需要用到 math/minuit2 目录之外的文件。这一问题通过添加 copy_standalone.cmake 文件得到了解决：该文件中的函数接收一个文件名列表，然后根据情况或直接返回原始源码目录中的文件名列表，或将文件复制到本地源码目录并返回新位置的列表，亦或在原始源码目录不存在时（即独立模式）仅返回新位置的列表。

# 将文件复制到源码目录中
cmake /root/math/minuit2 -Dminuit2-standalone=ON

# 从源码目录生成 .tar.gz 压缩包
make package_source

# 可选：清理源码目录
make purge

这仅面向想要制作源码包的开发人员 —— 普通用户不会传递该选项，也不会创建源码副本。

无论是在 ROOT 源码内部，还是使用单独发行的源码包，都可以直接运行 make install 或 make package（生成二进制包），而无需添加 standalone 选项。
